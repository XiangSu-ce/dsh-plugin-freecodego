sync/recalibration review signal, not permission to silently alter this record.

## Included scope and exclusions

The package carries 12 core CSVs (11 routed domains plus auxiliary reasoning profiles)
and 22 framework-stack CSVs: 34 tables, 2,385 rows, about 1.05 MB. UWP is
retained because upstream explicitly includes its legacy-only guidance. The search engine, CSV parser, data loader, and identity
resolver are local TypeScript ports.

Deliberately excluded: `google-fonts.csv` and `google-font-licenses.json` (a
separate roughly 1.18 MB raw-family/license dictionary),
`phosphor-icons-upstream.json` (the full roughly 824 KB icon dictionary),
platform-specific Skill wrappers and Python scripts, and the design-system
formatter/persistence code. The curated typography pairings and `icons.csv` remain
included. No tool writes generated files into a user's project.
